# ✅ To-Do List

A clean, responsive, and interactive **To-Do List Web Application** built with HTML, CSS, and JavaScript.

The project provides a simple interface for creating, completing, and removing tasks while demonstrating practical front-end development and JavaScript DOM manipulation.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ⚡ Dynamic task management
* 📱 Responsive user interface
* 🎨 Clean and user-friendly design
* 🔄 Real-time interaction without page reload
* 🌐 Runs directly in a modern web browser

## 🛠️ Technology Stack

* **HTML5** — Structure and semantic markup
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Application logic and user interaction

## 🎯 Project Objectives

This project was developed as a practical front-end application to strengthen JavaScript fundamentals and understand how interactive web applications are built using core web technologies.

The primary focus is on connecting the user interface with JavaScript logic through DOM manipulation and event-driven interactions.

## 📚 Concepts Practiced

* DOM Manipulation
* Event Listeners
* JavaScript Functions
* Arrays
* Loops
* Conditional Logic
* Dynamic HTML Elements
* Event Handling
* CSS Layout & Styling
* Responsive Web Design

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html` using **Live Server** or directly in a modern web browser.
